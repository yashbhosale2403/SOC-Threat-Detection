Detection & Response Pipeline Architecture

  1. Log Ingestion & Normalization: Raw attack traffic is parsed into a standardized JSON schema (Timestamp, Source, IP, User, Event).
  2. Dual Detection Engine: Rule Engine checks deterministic thresholds while Isolation Forest evaluates behavioral features to produce an Anomaly Score (0.0 - 1.0).
  3. Threat Intelligence: Correlates source IPs against known malicious IOC database (Tor, Mirai, botnets).
  4. Risk Scoring: Computes a unified 0-100 score combining Rule weight + ML Anomaly + Threat Intel + Asset Criticality.
  5. Event Correlation: Reconstructs the kill-chain progression across events into an actionable Incident.
  6. Remediation Dispatch: Proposes containment actions (e.g. Firewall IP Drop) awaiting analyst approval.
